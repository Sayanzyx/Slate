Política de Privacidade

Slate · Última atualização: novembro de 2026

O Slate é uma página inicial pessoal para o navegador, executada localmente no computador do próprio usuário. Esta política explica quais dados o Slate acessa e como são tratados.

Dados que o Slate acessa

Quando o usuário conecta uma conta Google, e somente após a sua autorização explícita, o Slate acessa os dados do Google Agenda para:

  • ler os eventos e compromissos da agenda;
  • exibir os participantes de cada evento;
  • responder a convites (aceitar ou recusar);
  • criar novos eventos a pedido do usuário.

O Slate também guarda localmente notas, tarefas, anexos, atalhos e configurações criados pelo próprio usuário.

Como os dados são usados

Os dados são usados exclusivamente para exibir as informações na página inicial do próprio usuário e executar as ações que ele solicita. Nenhum dado é usado para publicidade, análise de perfil ou qualquer outra finalidade.

Onde os dados ficam

Todas as informações ficam no computador do usuário: no armazenamento do navegador e em um servidor local executado na própria máquina. O Slate não possui servidores próprios e não envia os dados do usuário para a internet, exceto a comunicação direta com os serviços do Google necessária para buscar e gravar os eventos da agenda.

Compartilhamento

O Slate não vende, não aluga e não compartilha os dados do usuário com terceiros.

Uso de dados do Google

O uso das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O usuário pode desconectar a conta a qualquer momento nas configurações do Slate ou retirar a permissão diretamente na página da Conta do Google, em "Conexões com apps de terceiros".
